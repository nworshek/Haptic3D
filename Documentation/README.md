# Haptic3D

Unity-based haptic interaction system using a wearable
multi-finger haptic glove and ESP32/PCA9685 motor control.

## Repository Structure
- Assets — Unity scenes, scripts, models, and assets
- Firmware — ESP32-S3 haptic glove firmware
- Documentation — system and experiment documentation

## Hardware
- Seeed Studio XIAO ESP32S3
- PCA9685
- Multi-finger vibration motors

## Software
- Unity 2019.4
- Arduino/ESP32 firmware
